# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest (main) | ✅ |

## Scope

This project is a **static, client-side only** worksheet generator — no backend, no database,
no accounts, no user data leaves the browser (settings are stored in `localStorage` only).
The realistic attack surface is therefore limited to the deployed origin and its dependencies.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report privately through the [GitHub Security Advisory](https://github.com/forumdata-collab/mathsexercise/security/advisories/new)
("Report a vulnerability" button), or email the maintainer directly.

We aim to acknowledge reports within **48 hours** and will keep you informed until the issue is resolved.
